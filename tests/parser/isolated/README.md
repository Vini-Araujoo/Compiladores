# Testes isolados

Esta pasta guarda os testes legados escritos para validar subgramaticas durante o desenvolvimento das issues.

Eles foram separados dos testes finais porque muitos sao fragmentos sem `class` e metodo. A entrada oficial do parser sera testada nas pastas `issue_n/` com programas completos.

Os arquivos foram mantidos sem alteracao para preservar o rastreio do desenvolvimento. As novas suites integradas serao criadas nas pastas `issue_n/`.
